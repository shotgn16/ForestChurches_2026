First Run

Initial setup steps after installation or deployment.

1. Create the initial admin account
- Use the first-run wizard or seed an admin via configuration. Secure this account with MFA.

2. Configure global settings
- Set platform-wide email settings, OAuth providers, and logging targets.

3. Approve initial tenants
- If you maintain a whitelist, add initial churches or verify domain settings.

4. Test core workflows
- Create a test church tenant, add a ChurchAdmin user, create an event, and test registration and email notifications.

5. Backup baseline
- Take a full database backup and snapshot storage after initial setup.
