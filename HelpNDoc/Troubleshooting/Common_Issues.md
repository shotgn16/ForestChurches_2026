Common Issues

Sign-up failures

- Verify whitelist/email domain rules and check verification email delivery.

Email not sending

- Test SMTP credentials and check email logs for authentication errors or bounces.

Permissions errors

- Confirm role assignments and that the user is assigned to the correct tenant.

Missing registrations

- Check event visibility, registration window, and manual approval queues.

If logs are insufficient, enable debug logging temporarily and contact support with trace IDs.
