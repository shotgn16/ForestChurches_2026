Getting started as a Church

Overview

This guide walks new churches through the common onboarding steps: whitelisting, sign-up, initial configuration, and adding the first event.

1) Whitelisting and approval

- Request whitelisting: Contact the ForestChurches administrator or use the self-service request form on the public site. Provide the official church name, contact email, and a short description.
- Admin approval: An administrator reviews the request and adds the church to the whitelist. Approved church domains or email addresses are added to the tenant allowlist.

2) Sign-up

- Invitation or self-registration: If invited by an admin, use the invite link. Otherwise complete the sign-up flow. Use an email address from the allowed domain if domain-based whitelisting is used.
- Account verification: Verify the email address (click link in verification email).

3) Initial configuration

- Basic settings: Set church display name, address, timezone, and contact details.
- Roles: Add initial users and assign roles (Church Admin, Event Organizer).
- Email setup: Ensure outgoing email is configured (SMTP or configured provider) so notifications can be sent.
- Default templates: Review and customize email templates used for registrations and confirmations.

4) Add your first event

- Create event: From the Church dashboard, choose Add Event. Enter the title, description, date/time, location, and capacity.
- Registration form: Add fields you want to collect: attendee name, email, phone, notes, and any custom questions.
- Visibility: Decide whether the event is public or members-only.
- Save and publish: Save as draft if you want to preview; publish when ready.

5) Test the flow

- Register a test attendee to confirm registration emails and the attendee list flow work as expected.
- Check exported attendee CSV and/or check-in process.

Tips

- Use a dedicated administrative account for initial configuration to avoid accidental loss of access.
- Keep a documented list of user roles and responsibilities for your church staff.

If you encounter permission or email delivery issues, contact the system administrator for tenant verification and SMTP troubleshooting.
