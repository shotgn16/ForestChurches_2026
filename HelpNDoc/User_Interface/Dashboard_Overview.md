Dashboard Overview

Purpose

The dashboard is the primary landing page after sign-in. It gives at-a-glance information for administrators and organizers.

Common widgets

- Upcoming events: next scheduled events with quick actions
- Recent registrations: latest sign-ups awaiting approval
- Notifications: system messages, errors, or alerts
- Shortcuts: quick links to create events, invite users, or export data

Customizing

ChurchAdmins can often rearrange or toggle widgets based on role and preferences.

Tips

- Use the dashboard to spot pending approvals and high-attendance events early.
