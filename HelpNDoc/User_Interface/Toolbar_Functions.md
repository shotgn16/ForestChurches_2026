Toolbar Functions

Overview

Toolbars provide quick access to creation and action buttons inside list views and detail pages.

Common actions

- Add / New: create a new event or user
- Import / Export: CSV import and export
- Bulk actions: bulk email, bulk status change, bulk delete (restricted by role)
- Filters: quick filters for status (published, draft, cancelled) and date ranges

Keyboard shortcuts

- Common shortcuts (if implemented): N = new, E = edit selected, / = focus search

Accessibility

- Toolbars should be keyboard navigable and have proper ARIA labels for screen readers.
