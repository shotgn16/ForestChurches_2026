Menu Breakdown

Main navigation

- Dashboard: quick overview and shortcuts
- Events: event list, create event, recurring series
- People / Users: manage church users, invite, and roles
- Communications: email composer, templates, history
- Settings: church-level configuration and contact routing
- Admin Console: (PlatformAdmin only) global settings and tenancy management

Context menus

- Each item in the lists (events, users) has contextual actions: edit, export, duplicate, cancel.

Search

- Global search for events, users, and messages helps quickly locate records.
