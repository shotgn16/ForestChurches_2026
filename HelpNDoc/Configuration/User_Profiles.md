User Profiles

Overview

User profiles store contact details, role assignments, and preferences.

Profile elements

- Contact details: email, phone, address
- Role assignments: per-tenant roles and platform roles
- Preferences: notification preferences, language/timezone
- Activity: last login, audit trail of major actions

Managing profiles

- ChurchAdmins can update tenant-scoped profile fields; users can update personal preferences.
- Password resets and invite resends handled through the People/Users area.
