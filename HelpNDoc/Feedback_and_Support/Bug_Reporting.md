Bug Reporting

How to report a bug

- Provide steps to reproduce, expected vs actual behavior, environment (browser, OS), and trace IDs if available.
- Attach screenshots and relevant log excerpts.

Severity levels

- Critical: site or core functionality unavailable
- High: major feature broken for many users
- Medium/Low: UI issues or edge case bugs

Response

- Include expected SLAs for different severity levels as determined by the platform owner.
