Manage a church and manage a user

Managing a church

- Edit church details: From Tenants list, open a church and update metadata (name, address, timezone).
- Suspend or reinstate: Use the suspend control for abuse or compliance issues; reinstate after review.
- Tenant-level settings: Adjust registration policies, contact routing, and default event visibility.
- Export tenant data: Produce CSV exports for users, events, and message logs for compliance or backup.

Managing a user

- Search: Use the global user search by email or name.
- View profile: Inspect role assignments, tenant memberships, last sign-in, and audit trail for changes.
- Reset password / resend invite: Use the provided actions to help users regain access.
- Deactivate vs delete: Prefer deactivation to preserve historical records. Deleting should be a deliberate action with export/backup.

Audit and compliance

- Check audit logs before taking irreversible actions.
- Document reasons for suspension or deletion to support any future appeals or audits.

This page assumes the admin has PlatformAdmin or SupportAgent privileges. For tenant-level tasks, use the tenant's ChurchAdmin role instead.
