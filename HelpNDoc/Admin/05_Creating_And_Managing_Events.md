Creating and Managing Events (Admin guide)

Overview

This article covers event creation, editing, recurring series management, capacity and waitlists, and special admin-level operations such as transferring events between tenants and exporting event data.

Creating an event

- From the selected church or the global events area (if permitted), click Add Event.
- Enter title, description, location, date/time and organizer.
- Set capacity and registration options (open, invite-only, approval required).
- Add custom registration fields or attachments.

Recurring events

- Use the series option to create recurring instances (daily/weekly/monthly).
- When editing a recurring series, choose whether to update the entire series or a single occurrence.

Approvals and waitlists

- Approval workflow: Enable manual approval to require organizers to accept registrations.
- Waitlist: When capacity is reached, registrants can be added to a waitlist which auto-promotes when spots open.

Admin-only operations

- Transfer event: Admins can reassign ownership of an event to a different tenant or organizer when needed (used for consolidation or migration).
- Force cancel: Admins can cancel events and optionally bulk-notify attendees.
- Bulk export: Export all event instances and registrations for reporting or archival.

Safety and privacy

- If personal data is stored with registrations, ensure proper retention and export controls are used when sharing data.

Troubleshooting

- Missing attendees: Confirm event visibility and registration window. Check for manual approvals pending.
- Email notifications not sent: Confirm SMTP and template configuration for the tenant.

This guide is oriented to platform admins who need cross-tenant controls as well as tenant-level ChurchAdmin users managing events for their own church.
