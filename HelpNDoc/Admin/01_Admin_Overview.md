What it is: Admin overview

Purpose

The administrative area in ForestChurches provides global controls for the platform owner and trusted administrators. It is intended for cross-tenant tasks (where applicable) and for managing the whitelist, global email settings, and platform-level support.

Who should use it

- Platform administrators
- Support staff and technical maintainers
- Compliance officers for audit and data-export

Key capabilities

- Tenant (church) management: Approve, suspend or edit tenant metadata and whitelisting.
- User moderation: Search and manage user accounts across tenants where permitted.
- Global configuration: Email providers, OAuth client settings, and integration keys.
- System logs: View audit trails and platform health metrics.

Security

- Admin accounts should use MFA and be restricted by IP/role where possible.
- Actions are audited and reversible where possible through audit logs.

This article is a starting point for administrators — see dedicated admin-topic articles for operational tasks.
