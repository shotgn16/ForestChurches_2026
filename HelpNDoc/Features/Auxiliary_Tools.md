Auxiliary Tools

Overview

Auxiliary tools complement core features: imports, exports, testing utilities, and analytics.

Examples

- CSV import/export: bulk-create users or registrations and export reports.
- Test email sender: send test messages to verify SMTP and templates.
- Diagnostics: health checks, logs viewer, and background job queue status.
- Webhooks tester: simulate outbound webhook payloads for external integration testing.

Usage

- Use imports for initial data seeding; validate sample data before running large imports.
- Diagnostics should only be available to admins and support roles.
