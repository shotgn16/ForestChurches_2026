Shortcuts and Tips

Productivity tips

- Templates: create email templates for confirmations and reminders to save time.
- Segments: tag users (e.g., volunteers, newcomers) for targeted emails instead of broad lists.
- Use drafts: Save events as drafts to preview before publishing.
- Test flows: Always test registration and confirmation emails with a test attendee.

Keyboard shortcuts

- If supported by the UI, learn the top-level shortcut keys for new item creation and search.

Maintenance tips

- Regularly review and deactivate inactive users.
- Archive old events to keep the event list manageable.
