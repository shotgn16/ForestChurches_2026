Contacting a church and how it works

Overview

ForestChurches provides built-in ways for visitors and members to contact their church: public contact forms, direct messaging to roles, and event-related communications.

Methods of contact

- Public contact form: Available on the church’s public page. Submissions create a message record and optionally an email to designated recipients.
- Role-based contact: Contact forms can target a role (e.g., Pastoral Care, Admin). The message is routed to users in that role.
- Event contact: Each event can expose a contact field for questions; messages are attached to the event.
- Direct email: Users can use the church's listed contact email to communicate externally if enabled.

Message handling workflow

1. Submission: User fills the form and submits their message.
2. Routing: The system routes the message based on configured recipients (role, email list, or specific admin).
3. Notification: Designated recipients receive an email notification with the message and a link to view/respond in the web UI.
4. Reply: Staff can reply through their email client or via the admin message UI; replies are recorded if the reply goes through the system.

Privacy and moderation

- Moderation: Admins can review and remove inappropriate messages; spam protection or CAPTCHA can be enabled.
- Data retention: Contact messages are retained according to tenant retention rules. Sensitive data should be handled with care.

Best practices

- Assign a small team to monitor incoming messages daily.
- Set auto-response templates to acknowledge receipt for common queries.
- Keep contact forms minimal to reduce abandoned submissions; collect only necessary information.

If you need message routing changed (e.g., new role, different recipients), update the contact routing in the church settings or ask the system administrator to make tenant-level routing changes.
