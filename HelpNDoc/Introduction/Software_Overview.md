Software Overview

Purpose

This document describes the ForestChurches application at a glance: purpose, intended users, and high-level capabilities.

Summary

ForestChurches is a multi-tenant web application built on .NET 8 and Razor Pages to help churches manage events, people, and communications. It targets small-to-medium congregations, supporting volunteers and administrators with low-friction workflows for event registration, email communications, document handling, and basic reporting.

Audience

- Church admins, volunteers, and staff
- Platform administrators and IT teams
- Developers integrating with the system
