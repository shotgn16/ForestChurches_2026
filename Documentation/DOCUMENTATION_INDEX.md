## 🔐 Important Security Notes

- ⚠️ **Never store API keys** - Users provide credentials as needed
- ⚠️ **Validate all credentials** - Check before making API calls
- ⚠️ **Use HTTPS only** - All ChurchSuite API calls are encrypted
- ⚠️ **Log carefully** - Never log credentials or sensitive data
- ⚠️ **Handle errors gracefully** - Don't expose internal details

See: CHURCHSUITE_INTEGRATION_GUIDE.md → Security Considerations
